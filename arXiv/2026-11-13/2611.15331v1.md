# FOORT: Flexible Object-Oriented Ray Tracing

## authors:
#Daniel_R_Mayerson
#Seppe_J_Staelens
#Fabio_Bacchini

## summary:
We present FOORT (Flexible Object-Oriented Ray Tracing), an open C++ code for ray-tracing images of black holes and other compact objects in arbitrary spacetimes. FOORT is designed to offer flexibility and can handle horizons, naked singularities and numerical metrics, allowing it to ray-trace numerous different metrics including Kerr and other black holes, as well as horizonless objects such as fuzzballs and boson stars. New metrics, analytical or numerical, can be added with minimal effort, and geodesics are initialized at the camera without reference to conserved quantities, so no special structure of the metric is required. Besides the intensity observed from a geometrically and optically thin equatorial disk, FOORT is set up to track a number of diagnostics along each geodesic, such as the number of equatorial crossings and the radius of closest approach. Its adaptive mesh can refine the image on any of these diagnostics, efficiently resolving narrow features such as higher-order photon rings. Accompanying Python tools convert the output into images and interferometric visibility amplitudes. We describe the main features of the code, validate it against analytic results in the Schwarzschild and Kerr spacetimes, demonstrate it on several non-Kerr metrics, and characterize its scaling with the number of OpenMP threads. FOORT is lightweight, requiring only C++17 and OpenMP, and has already been used in a number of studies of black hole and compact-object imaging. The code is publicly available in a GitHub repository.
