# Dual N=1 Lagrangians for Argyres-Douglas theories

## authors:
#Minseok_Cho
#Jaewon_Song

## summary:
We find a new set of four-dimensional $\mathcal{N}=1$ Lagrangian gauge theories that flow in the infrared to $\mathcal{N}=2$ Argyres-Douglas theories of type $(A_1, A_{2n})$, $(A_1, A_{2n+1})$, $(A_1, D_{2n+1})$, and $(A_1, D_{2n+2})$. The new dual theories are given by $SU(2)^n$ quiver gauge theories with a number of gauge-singlet flip fields. This description provides dual theories for the previous $\mathcal{N}=1$ Lagrangian realizations given by $Sp(n)$ or $SU(n+1)$ gauge theories, exchanging the rank and the number of nodes in a quiver diagram.
