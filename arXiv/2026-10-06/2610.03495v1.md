# Carrollian Worldsheets on Carrollian Targets, When does ILST describe a null string theory?

## authors:
#M_M_Sheikh-Jabbari
#H_Yavartanoo

## summary:
Null string theory (NST) is a two-dimensional (2d) sigma-model on a Carrollian worldsheet with 2d diffeomorphisms, Weyl and Carroll-Weyl (CW) scalings as gauge symmetries whereas the Isberg-Lindström-Sundborg-Theodoridis (ILST) theory on a generic target space only realizes the first two and not the CW gauge symmetry. We show in this work that NST on the Carrollian target spaces (CTS) is well-defined if the background admits a homothetic kernel generator and that, it is described by the ILST theory on the same CTS. To this end, we formulate a minimal null string theory on CTS, starting from first principles and then discuss beyond minimal theories as deformations away from minimality. We study some classes of such deformations involving the clock one-from for ruled Carrollian spaces and/or connection on the Carrollian space. We discuss implications of this for the recently introduced null string holography. As examples CTS, we briefly discuss null strings probing black hole horizons and the null string holography in this context.
