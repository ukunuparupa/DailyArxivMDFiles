# Gravitational Path Integral and String Theory

## authors:
#Ashoke_Sen

## summary:
Gravitational path integral has had many applications in recent years. Using the example of supersymmetric index, which provides one of the most controlled tests of gravitational path integral, we argue that even in this controlled case, naive gravitational path integral cannot produce consistent results beyond low orders. However one can go further using stringy inputs, e.g. the choice of UV cut-off and the choice of correct path integration variable, without having to do full fledged string calculation. We also discuss to what extent we are led to string scale UV cut-off even if we begin with a supergravity theory without an a priori bias towards string theory. This is a review of mostly published results, but we clarify several details.
