# Interfaces in Long Range CFT$_1$

## authors:
#Bastien_Girault
#Miguel_F_Paulos

## summary:
We consider interfaces in the theory of a single free scalar in AdS$_2$ defined by adding relevant operators along portions of the boundary. We begin with Neumann/Dirichlet interfaces, computing the associated scaling dimension and $g$-factor ratio; we also explain how arbitrary interface correlators can be computed numerically efficiently. Then we move on to interfaces between generalized free field and long-range interacting theories such as long range Ising, determining many quantities in perturbation theory. Finally we setup a bootstrap problem for four-point interface correlator. We use this to find tight bounds on the $g$-factor ratio as a function of the interface scaling dimension.
