# Reconstructing Meson Parton Distributions from Mellin Moments with Artificial Neural Networks

## authors:
#Pietro_Dall_Olio
#Cristian_Del_Gobbo
#Khépani_Raya
#José_Rodríguez-Quintero

## summary:
We address the inverse problem of reconstructing a meson parton distribution function (PDF) or parton distribution amplitude (PDA) at a fixed scale from a finite set of Mellin moments. At finite moment order this map is ill posed in the Hadamard sense: the moments do not determine a unique, stable pointwise $x$-dependence, and small data perturbations can produce large changes in the reconstruction. We regularize the problem by restricting the admissible function class through constraints justified by first principles---support on $x\in[0,1]$, endpoint vanishing, unit normalization, and, for the pion, the exact $x\leftrightarrow 1-x$ symmetry---and by complementing these hard constraints with differentiable penalties that suppress the spurious multiple maxima and central concavity changes typical of ill-posed inversions. We parameterize the unknown function with two interchangeable neural cores, a multilayer perceptron (MLP) and a Kolmogorov--Arnold network (KAN), and find that the KAN reconstructs the target distributions more accurately, most markedly in the asymmetric (kaon) case. We attribute this advantage to the locality of the B-spline basis underlying the KAN, which localizes corrections during moment matching and damps the global oscillations to which the MLP is prone. Benchmarks against synthetic targets, using both ten and five input moments, support these conclusions.
