# Memory Effect for deformed gravitational waves

## authors:
#P_-M_Zhang
#M_Elbistan
#P_A_Horvathy

## summary:
Deformations of sandwich gravitational waves are considered. Squeezing a wave with pure displacement (DM) parameters to an impulsive wave, the DM property is lost, leaving us with the velocity effect (VM). For each fixed value of the deformation parameter $p$, DM can be restored by further increasing the amplitude which however diverge when $p\to\infty$, and no impulsive wave is obtained.
